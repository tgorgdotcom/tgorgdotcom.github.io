This is one of the first games I've created (next to a DOS-based number guessing game). I created it in [The Games Factory](http://clickteam.com/eng/prodindex.php#retired) back in 2002-2003. It was originally sold to friends and family for $5, but after realizing that there were some things that could be improved with the game, I decided to stop selling it. Since it has been awhile when I released marble panic for sale, I've decided to release the game for free. Have fun!

**NOTE:** The install also includes the Marble Panic Screensaver

For Windows 95/98/ME/XP
