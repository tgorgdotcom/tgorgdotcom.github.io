The tgorg Laugh Machine is probably the easiest programming project I had, and probably the most entertaining program I've made.  
  
The program is simple. After the program is installed, the user can click on the button to cause laughing sound to play. When pressed multiple times, the intensity of the laugh is greater. The laugh restarts at a low intensity when the button is pressed enough times (roughly four times).  
  
For Windows 95/98/ME/XP
